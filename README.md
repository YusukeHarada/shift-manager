# シフト管理アプリ

介護士向けの月次シフト管理Webアプリです。紙で配布されるシフト表を見ながら手入力し、カレンダー形式で確認・管理できます。

## 機能

- 月次シフトの手動入力（9種類のシフト区分）
- カレンダー表示 / リスト表示の切り替え
- シフト種別ごとの集計
- 次の出勤日の表示
- 月をまたいだナビゲーション

## シフト区分

| キー | 意味 | 紙面の記号 |
|------|------|-----------|
| 早 | 早番 | 早 |
| 早1 | 早番1 | 早1 |
| 遅 | 遅番 | 遅 |
| 夜 | 夜勤 | 半月記号 |
| 明 | 明け休み | ●（黒丸） |
| 当 | 当直 | ○（白丸） |
| 休 | 休み | × |
| α | 残業 | α |
| 会 | 会議 | 会 |

## 技術スタック

- React 18
- Vite 5
- Vitest（テスト）
- Vercel（ホスティング）
- Supabase（データベース、導入予定）

## セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# テスト実行
npm test

# ビルド
npm run build
```

## デプロイ

Vercel に GitHub リポジトリを連携してデプロイします。

1. https://vercel.com にアクセスしてGitHubでログイン
2. 「Add New Project」で本リポジトリを選択
3. 設定はデフォルトのまま「Deploy」

## 環境変数（Supabase 導入後に必要）

```
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```
