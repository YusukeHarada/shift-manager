# シフト管理アプリ

介護士向けの月次シフト管理Webアプリです。紙で配布されるシフト表を見ながら手入力し、カレンダー形式で確認・管理できます。

## 機能

- 月次シフトの手動入力（ベースシフト8種類 ＋ αオプション複数選択）
- シフト入力モード（シフトを先に選んで複数日付に一括登録）
- カレンダー表示 / リスト表示の切り替え
- シフト種別ごとの集計
- 次の出勤日の表示
- 月をまたいだナビゲーション
- 勤務時間表の参照（モーダル表示）
- Googleカレンダー向け iCal（.ics）エクスポート

## 入力方法

### 通常入力モード

日付をタップ → シフトを選ぶ → 保存。1日ずつ入力する場合に使う。

### シフト入力モード

ヘッダーの「入力モード」ボタンをタップして切り替える。シフト → 日付（複数可）の順に選んでまとめて保存。同じシフトが連続する日をまとめて登録するのに向く。

## シフト区分

### ベースシフト

| キー | 意味 | 紙面の記号 | 開始 | 終了 |
|------|------|-----------|------|------|
| 日 | 日勤 | 日 | 8:45 | 17:30 |
| 早1 | 早番1 | 早1 | 7:00 | 15:45 |
| 早 | 早番 | 早 | 7:30 | 16:15 |
| 遅 | 遅番 | 遅 | 10:15 | 19:00 |
| 夜 | 夜勤 | 半月記号 | 16:30 | 翌9:30 |
| 明 | 明け休み | ●（黒丸） | 19:00 | 翌7:00 |
| 当 | 当直 | ○（白丸） | 未定 | 未定 |
| 休 | 休み | × | - | - |

### αオプション（ベースシフトに追加可・複数選択可）

| キー | 意味 |
|------|------|
| 残 | 残業 |
| 会 | 会議 |
| 当 | 当直 |

## セットアップ

```bash
npm install

npm test      # テスト実行
npm run build # ビルド
```


## デプロイ

Vercel に GitHub リポジトリを連携してデプロイします。

1. https://vercel.com にアクセスしてGitHubでログイン
2. 「Add New Project」で本リポジトリを選択
3. 設定はデフォルトのまま「Deploy」
4. `Settings` → `Environment Variables` に環境変数を Production / Preview 両方に設定
5. 「Redeploy」を実行
